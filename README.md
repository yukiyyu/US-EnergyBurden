# Identifying Spatiotemporal Predictors of U.S. Residential Energy Burden with Geospatial Explainable AI

Data and code for reproducing the manuscript and Supporting Information figures and tables.

## Files

```text
data/
  spring_sample.csv
  summer_sample.csv
  fall_sample.csv
  winter_sample.csv
  monthly_burden_means.csv
  data_dictionary.xlsx
src/
  common.ipynb
  01_XGB.ipynb
  02_SHAP.ipynb
  03_PDP.ipynb
  04_GXGB.ipynb
  05_Maps.ipynb
  06_Trends.ipynb
  07_Validation.ipynb
output/
  GXGB.csv
  figures/
  tables/
```

| Notebook | Analysis and outputs |
|---|---|
| 01_XGB | Evaluate configurations in each of four seasons; select parameters, fit the overall and seasonal models; Figures 2 and S2 |
| 02_SHAP | Refit using the shared in-memory parameter selection; calculate SHAP and prediction-variance decomposition; Figures 3, 4, S3 and Tables S5–S6 |
| 03_PDP | Refit using the selected parameters; calculate partial dependence and 1,000 bootstrap refits per season; Figure 5 |
| 04_GXGB | Search all bandwidths from 30 to 200 in steps of 5 for the overall and four seasonal models; fit the selected local models; GXGB.csv and Table S2 |
| 05_Maps | Read the results generated by 04_GXGB; Figure 6 and Figures S4–S9 |
| 06_Trends | Calculate descriptive summaries from the supplied CSV files; Figure 1 and Tables S3–S4 |
| 07_Validation | Fit spatially held-out XGBoost models using the shared in-memory parameter selection; Table S7 |

## Map boundaries

Boundary products are available from the [U.S. Census Bureau](https://www.census.gov/geographies/mapping-files/time-series/geo/tiger-line-file.html).
